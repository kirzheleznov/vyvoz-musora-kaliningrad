Дважды кликните `index.html` — откроется в браузере. Сборка не нужна.

Для проверки мобильной версии: открыть в браузере → F12 → переключить на
вид телефона (Toggle device toolbar), ширина ~375 px.

## Деплой (бесплатно, чтобы открыть по ссылке с телефона)

**Вариант A — Netlify Drop (проще всего, без аккаунта-кода):**
1. Зайти на https://app.netlify.com/drop
2. Перетащить папку проекта целиком в окно браузера.
3. Получить публичную ссылку вида `https://<имя>.netlify.app` — отправить папе.

**Вариант B — GitHub Pages:**
1. Создать репозиторий, запушить файлы.
2. Settings → Pages → Source: `main` / `root` → Save.
3. Ссылка вида `https://<логин>.github.io/<репозиторий>/`.
